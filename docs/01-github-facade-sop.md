# docs/01 · GitHub 门面工程（脱敏版 L1）

> **完整可执行 SOP 属 🔒 协作层**，本页仅公开框架原则。

## 核心原则

**先治理，后美化。** 治理是信息架构，美化是化妆——顺序反了就是给乱房间喷香水。

## 四层治理框架（顺序不可换）

| 层 | 做什么 | 为什么 |
|----|--------|--------|
| 1️⃣ 仓库治理 | 隐藏无关 Fork、归档废弃仓库、规范命名、置顶核心项目 | 访客 3 秒内的第一印象由列表决定 |
| 2️⃣ 项目深耕 | 旗舰项目 README 结构化：声明 → 架构图 → 特性 → 快速开始 | 内容质量 > 一切装饰 |
| 3️⃣ 门面美化 | Profile README、徽章、联系通道 | 收益真实但排在最后 |
| 4️⃣ 声望正循环 | 上游 PR、Discussions、双语双轨 | 长期复利 |

## 已验证的判断标准（非通用清单）

- **统计卡门槛**：周提交 > 10 才挂，否则是自曝短板（对攻实证修正项）
- **徽章数量** ≤ 8，多了变墙纸
- 装饰性内容（横幅/Trophy 堆砌）对技术访客价值 ≈ 0
