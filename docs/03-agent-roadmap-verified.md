# docs/03 · AI Agent 项目能力路线图（脱敏版 L1）

> **排序依据、分层逻辑与 benchmark 设计属 🔒 协作层**，本页公开方向清单与排序原则。

## 排序原则（三条，全部实证修正而来）

1. **工程地基优先于能力扩展**——没有 CI 与类型基建，一切新功能都在沙上建塔
2. **可观测性是性价比之王**——对用户是信任，对你是调试刚需
3. **无 benchmark 不承诺**——任何「延迟降 X%」「成本降 Y%」上线前必须自测，测不出的不写进对外材料

## 方向全景（P0 → P4）

| 层级 | 方向域 |
|------|--------|
| **P0 工程地基** | CI/CD 与自动发版 · 语义缓存 · 代码质量基建 |
| **P1 核心差异化** | 成本路由与模型分层 · 记忆质量飞轮 · 子代理安全熔断 · 可观测性面板 |
| **P2 能力扩展** | 动态推理深度 · 多模态闭环 · Agent 互联协议（如 MCP） |
| **P3 商业化** | Open Core 分层 · 私有化/云托管 · 生态市场 |
| **P4 品牌社区** | 性能白皮书（有数据再发） · 上游反哺 · SLO 文档 |

## 方法论一句话

> 方向可以抄，数字不能抄——每项收益上线前自己测一遍，测出来的才是你的护城河。
